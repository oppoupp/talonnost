# Талонность.ру

Учебный MVP сервиса поиска врачей и записи на приём. Государственные и частные клиники представлены в одном интерфейсе: можно найти специалиста, посмотреть клинику на карте и выбрать время приёма.

**[Открыть сайт](https://talonnost.onrender.com)**

## Возможности

- Поиск врачей по специальности.
- Фильтры по району, типу клиники и времени приёма.
- Сортировка по рейтингу клиники, стажу врача и ближайшему свободному слоту.
- Карта клиник на Leaflet с данными OpenStreetMap.
- Избранные врачи, регистрация и вход.
- Запись на приём, просмотр и отмена записей в личном кабинете.

## Технологии

Интерфейс: React 18, Vite, Tailwind CSS, Zustand, Axios, date-fns и Lucide. Сервер: Node.js, Express, JWT, bcryptjs и Zod. Данные хранятся в JSON-файле; PostgreSQL пока не подключён.

## Содержимое репозитория

- `site-source.tar.gz` — исходники клиента и сервера без установленных зависимостей.
- `render.yaml` — конфигурация развёртывания на Render.
- `README.md` — описание проекта и инструкции.

После распаковки архива:

```text
client/                 React-приложение
  src/components/       Общие компоненты интерфейса
  src/features/         Поиск, запись, авторизация и кабинет
  src/services/         Обращения к API
  src/stores/           Состояние приложения
server/
  src/routes/           Маршруты API
  src/controllers/      Обработка запросов
  src/models/           Работа с данными и авторизацией
  src/data/data.json    Данные демонстрационной версии
  prisma/schema.prisma  Заготовка схемы для PostgreSQL
```

## Локальный запуск

Нужны Node.js 22 или новее, npm и Git.

```bash
git clone https://github.com/oppoupp/talonnost.git
cd talonnost
tar -xzf site-source.tar.gz
```

Запустите сервер:

```bash
cd server
npm ci
JWT_SECRET="replace-with-a-long-random-string" npm start
```

В другом терминале откройте папку `talonnost/client` и запустите интерфейс:

```bash
npm ci --include=dev
npm run dev
```

Интерфейс доступен на http://localhost:5173, API — на http://localhost:4000. В режиме разработки Vite перенаправляет запросы `/api` на сервер.

## Публикация на Render

В опубликованной версии Express обслуживает и API, и собранный интерфейс по одному адресу.

Команда сборки:

```bash
tar -xzf site-source.tar.gz && npm ci --include=dev --prefix client && npm run build --prefix client && npm ci --prefix server
```

Команда запуска:

```bash
npm start --prefix server
```

Переменные окружения: `NODE_ENV=production`, случайный `JWT_SECRET`. Порт задаётся Render через `PORT`. При использовании исходной команды сборки из `render.yaml` установите `NPM_CONFIG_PRODUCTION=false`, чтобы npm установил инструменты сборки клиента. Проверка API: `/api/health`.

## Ограничения MVP

Демонстрационные данные не являются реальным расписанием клиник. Сервис не подключён к ЕМИАС или медицинским информационным системам.

В бесплатном развёртывании на Render изменения JSON-файла не сохраняются при перезапуске или повторной публикации: регистрации и записи могут сбрасываться. Для постоянного хранения нужна база данных. Сохранённые локальные пользователи в опубликованный архив не включены.
